## 四、`旧版/` 不进 git 的原因与找回方式

`旧版/` 约 **75 MB**（其中 PPT 工作版本 65 MB），进 git 会让仓库翻倍。
已被加入 `.gitignore`。

**但被删/被移的文件原本都在 git 里，可按路径找回**：

```powershell
# 找某个文件的删除记录
git log --oneline --diff-filter=D --name-only | Select-String "文件名"

# 从某个提交里取出该文件
git show <commit>:<path> | Out-File 恢复位置
```
