## 2. 最重要的一件事：**把真实模型 API 跑通一次**

**P9 那张表里写着「W1 确认：选定 1–2 家，跑通一次最小调用并记录成本」。**

## 3. 需要验算的：P14 的三个误差源

新增页写了三个信号各自的误差来源与测法：

| 信号 | 怎么被估计 | 误差从哪来 | 怎么测传导 |
|---|---|---|---|
| 检索置信度 | 从得分分布推断取几个 | 得分噪声、同义改写、漏检 | 给得分注入噪声，看 k 与准确率如何变 |
| 信息预算 | 启发式 token 估算器 | 与真实分词器的偏差 | 估算值 ±20% 扰动，看决策翻转多少 |
| 网络状态 | 探测 RTT 与连接类型 | 瞬时抖动、探测失真 | 注入 RTT 抖动，看路由切换频率 |

**需要确认**：「±20% 扰动」「注入噪声」这些做法的**幅度依据**。

- 应该参照"token 估算器与真实分词器的实测偏差"来定，不是拍脑袋
- 如果现在定不下来，答辩时这样讲：**"三个误差源已经识别，注入幅度会参照 W2 实测的估算器偏差来定。"**
  —— 说清"幅度怎么定"，比给一个没有依据的数字强
