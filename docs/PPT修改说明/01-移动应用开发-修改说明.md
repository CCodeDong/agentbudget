## 1. 必须改的：封面（P1）

**现状**：

```
小组：XXX / XXX / XXX　　指导教师：XXX
学院：计算机科学与技术学院　　日期：2026 年 XX 月
```

**要改成**：真实的三人姓名、指导教师、日期。

> 每队 **≤3 人**（含队长）。如果只有 2 人，删掉一个名字。

---

## 2. 必须改的：团队分工（P13）

**现状**：

| 模块 | 负责内容 | 完成判据 |
|---|---|---|
| A 采集 + 感知 | 相机 / 相册 / 文件导入 → OCR → 结构化文本 | 真机拍照能出文字 |
| B 索引 + 检索 | 端侧建库 → 查询 → 命中片段与原图高亮 | 按词能检索到原文 |
| C 调度 + 工程 | 预算策略 + 决策面板 + 签名与上架材料 | 决策面板 + 可提交的签名包 |

**要做的**：把 A / B / C 对应到具体的人。

**怎么改**：在"模块"那一列前面插一列"负责人"，填名字。

> 不要改成平均分配的描述（如"三人共同负责"）——**分工页的价值就在于"谁负责什么"，含糊会被追问。**

## 3. 需要复核的：生态数据（P4）

**现状数字**：

- HarmonyOS 是中国**第二大手机操作系统**
- 注册开发者 **1100 万+**、应用与服务 **40 万+**
- **HarmonyOS 7（API 26）** 于 2026 年 9 月发布

**要做的**：去官网查最新口径，**在页脚标上来源与时间**。

> 原稿的备注里就写了"建议答辩前用官方最新口径复核一次"。
> **查不到就删掉数字、只留定性描述**——一个没有出处的数字，比没有数字更危险。
