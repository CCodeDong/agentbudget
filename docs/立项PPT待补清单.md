## 二、必须补的三整页（现在缺）

### 🔴 ① 技术架构图（缺整页）

**为什么要**：立项 PPT 里没有架构图，几乎一定会被问"你打算怎么搭"。

**画什么**：

```
┌─────────────────────────────────────────┐
│  界面层：搜索框 / 结果列表 / 高级面板      │
├─────────────────────────────────────────┤
│  调度层：预算策略（复用已有 agentbudget）  │
│         决定"这次取几段"                  │
├─────────────────────────────────────────┤
│  检索层：BM25（自研，纯 ArkTS）            │
│         索引 / 打分 / 排序                │
├─────────────────────────────────────────┤
│  解析层：txt / md 解析；OCR（可选，降级）  │
├─────────────────────────────────────────┤
│  存储层：应用沙箱（索引持久化）            │
└─────────────────────────────────────────┘
         ❌ 无网络层 —— 这是刻意的
```

**重点**：图里要**明确标出"没有网络层"**——这是我们的差异化，也是合规主张的支撑。

**谁做**：需要一点技术理解，建议你和懂代码的队友一起。

**为什么要**：立项 PPT 讲产品，不给界面等于没讲。

**画什么**（3 个界面的草图即可，不用高保真）：

**谁做**：**不需要写代码**。用纸笔画拍照、或用任意画图工具（Figma / PowerPoint 本身），**能表达清楚就行**。
