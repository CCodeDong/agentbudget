## 五、提审说明文案（可直接粘贴）

> 用途：AGC 提审时通常有"备注/审核说明"字段。写清这几条，能减少审核员追问。

```
应用名称：离线资料库
应用类型：工具类（个人资料检索）

一、应用功能
用户把课堂讲义、书页照片、笔记片段导入本机资料库，用自然语言描述记得的
内容，应用在本机完成全文检索并返回原文片段与高亮位置。

二、无账号、无社交、无支付
本应用不需要注册登录，没有用户体系，不包含聊天、评论、分享、打赏、
广告、支付等任何功能。

三、无网络权限（重要）
本应用在 module.json5 中声明权限为空（requestPermissions: []），
不申请 INTERNET 权限，运行期间不发起任何网络请求，不向任何服务器
传输数据。全部资料仅保存在应用本机沙箱目录内。

四、不含生成式人工智能
本应用不生成任何文本或图像。图片文字识别调用系统自带的 OCR 能力，
仅用于把用户自己的图片转成可检索文字，识别结果先填入输入框由用户
确认后才入库。

五、数据来源
全部内容由用户自行导入，应用不抓取、不下载、不内置任何第三方内容。

六、权限说明
应用不申请任何系统权限。相册图片与文件均通过系统选择器由用户主动
挑选，应用只获得用户选中的那一个文件的临时访问 URI。
```
