# 应用上架规划（移动应用开发课程）

> **结论先说：要提前规划，而且有一项必须这周就启动。**
>
> 更新时间：2026-09 ｜ 剩余时间约 2–3 个月

## 一、时间账：为什么不能等

上架不是"打包 → 提交 → 等几天"。国内上架有**三个前置资质**，其中两个周期很长：

| 环节 | 周期 | 能否并行 |
|---|---|---|
| **软件著作权（软著）** | **30–60 个工作日**（约 1.5–3 个月） | 可与开发并行 |
| **App 备案**（工信部） | **约 15–20 个工作日**，全程约 1–1.5 个月 | 可与开发并行 |
| 开发者账号认证 | 1–2 周 | 已完成 ✅ |
| 应用市场审核 | 1–7 个工作日 | 必须最后做 |

**关键风险**：

> 软著 30–60 个工作日 ≈ **1.5–3 个月**，而你的剩余时间正好是 2–3 个月。
> **如果软著是必需的，那么"现在开始办"刚好够用，"下个月再说"就来不及了。**

而且这三项**互不依赖，可以并行**——所以正确的做法是**同时启动**，而不是排队做。

## 三、行动方案

### 第 0 步（今天）：问清楚两件事

这两件事的答案决定后面所有安排，**不能猜**：

1. **问课程老师**：上架是必须上华为应用市场，还是任何渠道都可以？验收时看什么（截图？链接？还是安装量）？
2. **问华为开发者社区**：非游戏类鸿蒙应用，个人开发者上架，**是否必须软著？单机应用是否必须备案？**

> 去华为开发者社区提问时，把这两句原话贴上：
> - "个人开发者上架 HarmonyOS 应用，非游戏类，是否强制要求软件著作权证书？"
> - "应用无服务端、纯本地功能，是否仍需完成 App 备案才能上架？"

### 第 1 步（本周内）：能启动的都启动

**与答案无关、无论如何都要做的**：

| 事项 | 说明 |
|---|---|
| 开发者实名认证 | ✅ 已完成（你配签名时做过） |
| 隐私政策页面 | 需要一个**可公开访问的 URL**，写明收集什么数据、如何删除 |
| 用户协议 | 同上 |
| 应用图标 / 截图 / 简介文案 | 按应用市场规范尺寸制作 |
| **软著申请材料** | 源代码前后各 30 页 + 说明书；**先准备着，答案是需要就立刻提交** |

**如果答案是需要软著**：**本周就提交**。30–60 个工作日，早一周就是早一周。

**如果答案是单机免备案**：省掉一个多月，但要留证据（把官方答复截图存档）。

### 第 2 步：应用本身要改造成"能给别人用的东西"

**这是被低估的工作量。** 我们现在的应用是**给研究者看的编排控制台**——普通用户打开会完全不知道这是什么。

上架应用市场的应用必须：

| 要求 | 我们现在的状态 |
|---|---|
| 打开就能明白是干什么的 | ❌ 全是 `edge` / `structured` / `two-stage-top3` 这种术语 |
| 有明确的用户价值 | ⚠️ 有价值（省流量/省电），但**没有对用户表达出来** |
| 功能完整，不是 Demo | ⚠️ 目前是可演示，但不是可用产品 |
| 不崩溃 | ✅ 已修复 A2A 崩溃问题 |

**改造方向（建议）**：

把"调度器控制台"包装成一个**用户能理解的应用**，例如：

> **「省流助手」**——自动判断当前网络状况，决定 AI 功能在本地跑还是用云端，
> 帮你在弱网下也能用、在流量紧张时少花流量。

界面要改成：
- 打开是一个**开关 + 简单的状态显示**（"当前：本地模式，已为你节省 XX MB"）
- 调度细节收进**「高级」**页面，给想看的人看

> 这样做的额外好处：**研究内容变成了"高级设置"，而不是主界面**。
> 既满足上架要求，又不损失课程要展示的技术内容。

### 第 3 步：提交审核

- 准备好所有材料后提交
- 审核 1–7 个工作日
- **被拒是常态，要预留返工时间**（至少留 2 周余量）

## 四、时间线建议（假设今天开始，剩 3 个月）

```
第 1 周   ├─ 问老师 + 问华为社区（决定路径）
          ├─ 启动软著材料准备
          └─ 写隐私政策与用户协议
第 2–3 周 ├─ 软著提交（若需要）
          ├─ 备案材料准备（若需要）
          └─ 开始应用界面改造
第 4–8 周 ├─ 等待软著 / 备案（并行进行界面改造）
          └─ 制作图标、截图、文案
第 9–10周 ├─ 应用改造完成，内部测试
          └─ 提交备案 / 取得软著
第 11 周  ├─ 提交应用市场审核
第 12 周  └─ 应对驳回、返工、重新提交
```

**余量只有约 2 周**——这就是为什么第 1 周必须把所有事情问清楚。
