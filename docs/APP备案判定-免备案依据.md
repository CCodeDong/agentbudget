# APP 备案判定：离线资料库是否需要备案

> **结论：无需备案。**
> **依据：通信管理局官方答复（原文引用见下）。**
> **判定时间**：2026-10-28

---

## 一、结论

**「离线资料库」（`com.xjtu.offlinelib`）属于「单机不联网的 APP」，无需办理 APP 备案。**

---

## 二、官方依据（原文）

**来源**：内蒙古自治区通信管理局 · 局长信箱 · 办件编号 `NMGZZQ20230800915`
**URL**：<https://nmca.miit.gov.cn/jactpub/front/mailpubdetail.do?sysid=11&transactId=606118>
**答复时间**：2023-08-17

**提问**：

> 1. 联网的APP和未联网的APP均需要备案吗？

**官方答复（原文）**：

> **1. 联网的APP和未联网的APP均需要备案吗？**
>
> **单机不联网的APP、小程序无需备案；**

同一答复还说明了需要备案的情形与流程：

> APP主办者通过其网络接入服务提供者或分发平台，通过"国家互联网基础资源管理系统"
> （即ICP/IP地址/域名信息备案管理系统），采取网上提交申请、查验审核方式进行。
> ……由省级通信管理局进行审核，材料齐全并准确的，**在二十个工作日内予以备案**。

---

## 三、我们为什么属于「单机不联网」

判定标准是**应用是否提供互联网信息服务**。逐项对照：

| 判定项 | 本应用实际情况 | 证据位置 |
|---|---|---|
| 是否申请网络权限 | **否**。`requestPermissions: []`，**一个权限都没有** | `entry/src/main/module.json5` |
| 是否发起网络请求 | **否**。代码中无任何 HTTP / Socket / WebSocket 调用 | `app/offlinelib/entry/src/main/ets/lib/` 全部源码 |
| 是否内置第三方 SDK | **否**。无统计、无埋点、无广告、无崩溃上报 | 无第三方依赖（`oh-package.json5` 依赖为空） |
| 是否有服务端 | **无**。没有服务器、没有域名、没有云函数 | — |
| OCR 是否上云 | **否**。使用 HarmonyOS 系统端侧识别能力，图片不离开设备 | `lib/realocr.ets` |
| 数据存放位置 | 应用私有沙箱 `/data/app/el2/.../com.xjtu.offlinelib/` | `lib/librarystorage.ets` |
| 是否需要账号 | **否**。无注册、无登录、无用户体系 | — |

**七项全部指向同一结论：不提供互联网信息服务。**

## 四、可以拿出来核实的证据（四层）

如果有人质疑"你说不联网就不联网？"，按这四层给证据。

| 层 | 怎么做 | 现在的状态 |
|---|---|---|
| **① 声明层** | 展示 `module.json5` 里 `"requestPermissions": []` | ✅ 可直接展示 |
| **② 代码层** | 全量搜索网络 API（`http` / `socket` / `fetch` / `XMLHttpRequest` / `@ohos.net`），结果为 0 | ✅ 可跑脚本证明 |
| **③ 运行层** | 开飞行模式，全部功能正常 | ⏳ 需设备录屏 |
| **④ 网络层** | 抓包，无任何出站连接 | ⏳ 需设备 |

> **取证建议**：②③④ 三层都是"别人能自己复核"的证据，
> 对审核和答辩都比口头说明有力。

## 五、如果应用市场仍然要求备案号怎么办

**这是现实风险**：分发平台可能机械地要求填备案号，而不区分是否需要备案。

**应对顺序**：

1. **先看平台实际的必填项**。AGC 提审流程里，备案号通常是**条件必填**——
   若填"不涉及互联网信息服务"，可能根本不需要填。
2. **若强行要求**，提供本节第二条的官方答复原文 + 第三条的七项对照 + 第二条的证据，
   说明属于"单机不联网应用，无需备案"。
3. **仍被拒**，走平台工单说明情况，附官方答复截图。

> ⚠️ **不要为了"填个号"去办不需要办的备案。** 备案需要接入服务商或分发平台
> 代为核验，没有服务器/域名时根本无从办起。

## 附：需要备案的情形（对照用）

同一答复并未列出豁免清单，但从"单机不联网无需备案"可反推：
**只要提供互联网信息服务，就需要备案**，例如——

- 应用内有服务端 API 调用（哪怕是读公告、上报崩溃）
- 应用有账号体系，登录需要联网
- 应用内内容来自服务端（资讯、课程、商品）
- 使用云端 OCR / 云端大模型推理

**本应用一项都不涉及。**
