## 五、时间估算的诚实说明

| 估算项 | 依据 | 可靠度 |
|---|---|---|
| 手动操作耗时（建应用、生成证书、填表） | 按实际步骤数估 | **中**——首次操作常比预期慢 |
| 证书审核等待 | 一般几分钟到数小时 | **低**——平台侧不可控 |
| 应用审核 1–3 个工作日 | 行业通例 + 官方口径 | **低**——我抓不到官方正文（文档站是 JS 渲染） |
| 软著 20–30 个工作日 | 版权中心公开口径 | **中**——可能因补正延长 |
| release 验证 30 分钟 | **我做过同类验证** | **高** |
| 补截图 45 分钟 | **我做过同类操作** | **高** |

**我没有把"可能被拒"算进合计。** 首次提审被拒是常见情况，每轮返工约 1–3 天。
**建议在截止日前预留 1–2 轮返工的时间。**
