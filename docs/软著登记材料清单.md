## 四、⚠️ 一个必须先处理的工程问题

**`app/offlinelib/entry/src/main/ets/lib/` 是 `projects/offlinelib-core/src/` 的手工复制。**

现在两者 SHA256 完全一致，但**没有任何机制保证一直一致**。

**风险**：如果我在 `projects/offlinelib-core/` 改了个 bug 忘了同步，
软著登记的代码和实际构建的代码就**不是同一份**了。

**对策**：已加校验脚本 `tools/gen_softcopyright.py check`，生成文档前会先做 SHA256 比对，不一致直接拒绝生成。
