**日期**：2026-10-24
**设备**：MateBook Pro（HAD-W32）/ 2in1 / API 23

## 一、深色模式：用资源限定词，不做自建开关

**做法**：把 82 处硬编码色值抽成 15 个语义色，声明在资源里。

```
resources/base/element/color.json   <- 浅色
resources/dark/element/color.json   <- 深色（dark 限定词）
```

之所以不用"自己加一个开关 + 一堆三元表达式"：
系统的深色模式切换会自动选中 `dark/` 下的资源，
**应用不需要感知主题状态，也不需要在每个用到颜色的地方判断**。

## 二、宽屏适配：限宽 + 居中

**做法**：内容列 `constraintSize({ maxWidth: 900 })`，外层居中。

| 形态 | 宽度 | 效果 |
|---|---|---|
| 手机竖屏 | 约 400vp | 占满，**无变化** |
| 手机横屏 | 约 800vp | 占满，**无变化** |
| 平板 / 2in1 横屏 | 约 1280vp | 居中在 900vp，两侧留白 |

**为什么不做双栏**：真正的双栏（列表 + 详情同屏）是更好的形态，
但改动面大；限宽已经解决了"一行正文被拉到 1200vp、眼睛要横扫"这个主要问题。

### 已验证

截图里可以看到：卡片区域比改动前**内缩并居中**，底部标签栏也跟着收进来了。
