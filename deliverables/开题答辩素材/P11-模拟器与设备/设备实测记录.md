## 一、实测过的设备

| 设备 | 型号 | 形态 | 系统 | API | 连接方式 |
|---|---|---|---|---|---|
| **MateBook Pro** | HAD-W32 | **2in1** | OpenHarmony-6.1.0.115 | **23** | 无线（`hdc tconn`） |
| **Pura 90 Pro** | 模拟器 | **phone** | emulator 7.0.0.107 | **26** | `127.0.0.1:5555` |

### 设备信息是怎么查的

```powershell
hdc shell param get const.product.model              # 型号
hdc shell param get const.product.devicetype         # 形态 ← 关键
hdc shell param get const.ohos.apiversion            # API 版本
hdc shell param get const.product.software.version   # 系统版本
```

**`const.product.devicetype` 是最该先查的一个**——
它决定这台设备属于哪种形态，进而决定哪些能力可用（见 [`../P6-平台能力/`](../P6-平台能力/)）。

## 二、三个实测结论

### 结论 1：模拟器镜像不含 HMS Core

```powershell
hdc shell "bm dump -a" | Select-String 'hms|agent'
# 模拟器：无任何匹配
# 真机 MateBook：有 com.huawei.hms.huaweiid、com.huawei.hms.payment 等
```

**含义**：任何依赖 HMS Kit 的功能，**在模拟器上都不可能工作**。

### 结论 2：真机的 HMS 包也不一定够用

MateBook 上虽然有若干 `com.huawei.hms.*` 包，**但没有 Agent 相关的包**。
而且它是 **2in1** 形态，而 `AI.Agent.AgentKit` 在元数据里**不对 2in1 公开**。

**含义**：**"有 HMS 包"不等于"有你要的那个 Kit"**。

### 结论 3：设备 API 可能低于 SDK API

| | 版本 |
|---|---|
| 电脑上的 SDK | **API 26**（HarmonyOS 26.0.0） |
| 真机 MateBook | **API 23** |

**而且电脑上只装了一个 SDK 版本，无法降级编译。**

**含义**：编译通过 ≠ 设备上能跑。凡是用到较高 API 的功能，**都要先确认目标设备的 API**。

## 三、对「离线资料库」的四条直接启示

| # | 启示 | 依据 |
|---|---|---|
| 1 | **必须在真机或云真机上验证 OCR** | 模拟器无 HMS，OCR 跑不了 |
| 2 | **Kit 依赖要抽成可降级模块** | 缺失时是**崩溃**，不是降级（见 `模拟器崩溃实证.md`） |
| 3 | **第 1 周就确认目标设备的 API** | 设备 API 可能低于 SDK，高版本 API 会失效 |
| 4 | **无线调试可用，取证不受 USB 限制** | 我们用 `hdc tconn` 成功连接 |

## 四、一个可复用的设备排查流程

```powershell
# 1. 设备在不在
hdc list targets

# 2. 无线连接（设备端先开"无线调试"，读出 IP:端口）
hdc tconn <IP>:<端口>

# 3. 这台设备是什么
hdc shell param get const.product.devicetype    # 形态
hdc shell param get const.ohos.apiversion       # API

# 4. 有没有你需要的 Kit
hdc shell "bm dump -a" | Select-String 'hms'

# 5. 应用启动即崩？取崩溃日志
hdc file recv /data/log/faultlog/faultlogger/<最新>.log ./crashlog
#    看 LastFatalMessage 那一行
```

## 五、诚实说明

- 这两台设备**都不是「离线资料库」的目标设备**（一台是 2in1，一台是模拟器）
- 我们**没有在真正的鸿蒙手机上测试过任何 HMS Kit**
- 因此"OCR 在真机上效果如何"**我们不知道**——P11 说"模拟器不支持 AI 能力"是对的，
  但**真机上的实际表现需要你们自己验证**
- AGC 云调试（P11 提到的免费方案）我们**没有实测**
