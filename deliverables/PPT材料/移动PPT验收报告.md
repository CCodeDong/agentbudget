## 二、⚠️ 三个排版风险：必须处理

### ① 字体**完全没有嵌入**（0 个）

检测到 7 种字体：

| 字体 | 使用次数 | 风险 |
|---|---|---|
| 微软雅黑 | 424 | Windows 自带，低风险 |
| **Noto Sans SC** | **329** | ⚠️ **非 Windows 自带，会回退** |
| 仿宋 | 203 | Windows 自带 |
| Calibri / Georgia / Arial / Consolas | 249 | Office 自带 |

**最严重的是 Noto Sans SC（329 处）**——如果放 PPT 的电脑没装这个字体，
会被替换成别的字体，**宽度变化会导致排版错乱**。

**修法**：PowerPoint → 文件 → 选项 → 保存 → 勾"将字体嵌入文件"，
并选"嵌入所有字符"（否则部分中文字不会嵌入）。

### ② emoji 共 16 处（✅13 / ❌2 / ⏳1）

主要集中在两页：

| 页 | 内容 |
|---|---|
| **P5 现有方案对比表** | ✅❌ 共 11 处，标"能不能搜正文 / 能不能离线" |
| P8 | ✅ 2 处（已实现并验证 / 已实现并实验） |
| P16 | ✅ 2 处 + ⏳ 1 处（判据达成情况） |

**风险**：`✅❌⏳` 只在 Segoe UI Emoji 里有字形。
Windows 10/11 一般有，但：
- **导出 PDF 后到别的设备可能变方块**
- **Mac 上打开会显示成不同样式**
- 打印时可能变成空框

**修法（二选一）**：
1. 换成文字："通过 / 未通过 / 进行中"
2. 换成几何图形：● / ○ / ◐（在主流中文字体里都有字形）

### ③ 箭头 `→` 共 18 处

`→`（U+2192）**不在 GB2312 字符集里**。微软雅黑有，但**仿宋可能缺字形**（203 处用到仿宋）。

**修法**：确认用仿宋的那些文字里有没有 →。有的话改成"至"或"—>"。

## 三、修复优先级

| 优先级 | 修什么 | 为什么 |
|---|---|---|
| **1** | **嵌入字体**（尤其 Noto Sans SC） | 不嵌可能导致整份 PPT 排版错乱 |
| **2** | **替换 16 处 emoji** | 打印和跨设备可能变方块 |
| 3 | 检查仿宋段落里的 → | 缺字形时显示为空框 |

> 这三个问题在**你自己电脑上大概率看不出来**——因为字体都在、emoji 有字形。
> 它们只在**换机、导出 PDF、打印**时才暴露。
> 而开题答辩现场用哪台电脑，你控制不了。
