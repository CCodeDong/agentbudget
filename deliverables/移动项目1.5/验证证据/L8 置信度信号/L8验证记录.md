# L8 识别置信度信号：一次失败的尝试与最终方案

**日期**：2026-10-24
**设备**：MateBook Pro（HAD-W32）/ 2in1 / API 23

---

## 一、为什么会有这一轮

L7 的实测结论是：**OCR 的失败方式是"漏认"而不是"错认"**
（最差那张图召回 28%、精确率 100%）。

据此推论：字符覆盖率应该能预警漏认。

**这个推论是错的。** 下面记录错在哪 —— 因为错的地方本身有信息量。

---

## 二、失败方案：字符覆盖率

### 做法

用 OCR 返回的每行 `cornerPoints` 算出行框宽高。
中日韩字形近似正方形，所以：

```
应有字数 ≈ 行宽 ÷ 行高
覆盖率  = 实际字数 ÷ 应有字数
```

这个量对字号天然不变（每行用自己的行高做尺度），看起来很有道理。

### 实测结果（12 张图）

| 图 | 召回 | **覆盖率** |
|---|---|---|
| 清晰 | 100% | 1.47 |
| 小字号 | 100% | **1.72** |
| 旋转 15° | 100% | 4.01 |
| 噪声 | 100% | 1.19 |
| **小字+模糊** | **28%** | **1.74** |

**最差的那张图（召回 28%）覆盖率和正常图一模一样。**

### 为什么必然失败

`应有字数` 是从**检测到的行框**算出来的。

**如果 OCR 整行都没检测到，那一行的框也不存在。**
于是实际字数和应有字数**一起缩小**，比值自我归一化，对漏认天然免疫。

> **一句话：检测器的盲区，在它自己的输出里是看不见的。**

这不是实现 bug，是方法本身的缺陷。
任何"只用 OCR 输出"构造的指标都会有同样的问题。

---

## 三、最终方案：图片锐度（独立于 OCR 输出）

### 做法

直接读 PixelMap 的像素，算相邻像素灰度差的平均绝对值：
```
锐度 = mean(|g(x+1,y) - g(x,y)| + |g(x,y+1) - g(x,y)|)
```
按约 200×100 个采样点抽样，避免对整张图求和。

**关键点：它在 OCR 之前计算**，因此完全不依赖识别结果。

### 实测结果

| 图 | 召回 | 锐度 | 置信 | 判定 |
|---|---|---|---|---|
| 噪声 | 100% | 27.9 | 0.90 | 收下 ✓ |
| 旋转 15° | 100% | 12.9 | 0.90 | 收下 ✓ |
| 旋转 6.5° | 100% | 12.6 | 0.90 | 收下 ✓ |
| 清晰 | 100% | 11.6 | 0.90 | 收下 ✓ |
| 行楷 | 98% | 10.1 | 0.90 | 收下 ✓ |
| 楷体 | 100% | 7.5 | 0.90 | 收下 ✓ |
| 高斯模糊 | 100% | 5.4 | 0.90 | 收下 ✓ |
| 低对比 | 100% | 2.7 | 0.90 | 收下 ✓ |
| 小字号 | 100% | 2.5 | 0.90 | 收下 ✓ |
| 强模糊 | 93% | 2.4 | 0.90 | 收下 ✓ |
| 极低对比 | 100% | 1.6 | 0.90 | 收下 ✓ |
| **小字+模糊** | **28%** | **1.3** | **0.30** | **重拍 ✓** |

**阈值 1.5，12 张全部分类正确。**

### 第一版阈值定错了

我一开始把阈值定在 18 / 12 / 7 三档，结果：
- 清晰（11.6）被判 0.45
- 小字号（2.5）、低对比（2.7）、极低对比（1.6）全被判 0.15
- **真正失败的那张（1.3）也判 0.15 —— 看起来"对了"，但 4 张好图被一起误杀**

**误杀和漏杀一样糟**。是按实测分布重定到 1.5 才对。

---

## 四、⚠️ 这个方案仍然不可靠，必须说清楚

| 局限 | 具体说明 |
|---|---|
| **分隔带极窄** | 成功最低 1.6，失败 1.3，只差 0.3。**分隔一个点 = 高度疑似过拟合** |
| 样本只有 12 张 | 全部是合成图，不是真实拍摄 |
| 锐度 ≠ 识别质量 | 低对比（2.7）看起来"糊"，但 OCR 认出 100%。**OCR 比"看起来清楚"稳得多** |
| 只对这台设备成立 | 换设备、换分辨率都需要重标 |

**所以这个置信度只能用来"提示用户核对"，绝不能用来"自动丢弃"。**

而这恰好和我们已有的设计一致：**识别结果从来不会自动入库**，
只填进输入框，由用户看一眼再点「加入资料库」。

> **结论：任何自动判据都不如让用户确认可靠。**
> 置信度的作用是"提醒注意"，不是"代替判断"。
