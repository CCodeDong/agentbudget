## ⚠️ 先说明两个不同的"版本号"

这个包里会出现两个版本号，**它们指的不是同一件事**：

| 名称 | 值 | 含义 |
|---|---|---|
| **材料包版本** | **1.5** | 这份交付物的迭代编号，每次补充材料就递增 |
| **软著登记版本** | **V1.0** | 已提交到中国版权保护中心，**证书上就是这个** |

所以 `软著/` 目录里的文件名保持 `V1.0` 不变——**改了就和证书对不上了**。

## 如何复现（需要 Node 与 DevEco Studio）

**跑单元测试**（不需要鸿蒙设备）：

```powershell
# 需要 typescript 与 node
cd 源码\核心库-src
# 把核心库、test、eval 放回 projects/offlinelib-core 结构后：
python tools\olib.py test        # 101 个测试
python tools\olib.py eval        # 真实语料检索评估
```

**构建应用**：用 DevEco Studio 打开 `源码/应用-ets/` 的上级工程目录，
或参照 `关键文档/ArkTS测试策略.md`。

> ⚠️ 安装到设备需要签名 Profile。调试签名会白名单特定设备 UDID，
> 换设备需重新生成。详见 `关键文档/AGC签名申请指南.md`。

## 打包与更新

这个包由脚本组装，不是手工复制：

```powershell
python tools\make_packages_1_5.py
```

手工复制会出现"包里是旧版本"的问题——**本包曾经就装着旧的 48 页源代码文档，
而实际提交的是 60 页**。用脚本可以避免。
