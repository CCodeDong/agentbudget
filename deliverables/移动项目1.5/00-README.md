## 做 PPT 前必须改的三处

1. **周制**：原稿"16 周制、第 6 周" → **16 周制、第 7 周**
2. **状态语态**：统一为【已完成】/【进行中】/【未开始】
3. **不严谨表述**："唯一""全部""彻底" → 改为可核实的范围限定

## 做图时的 4 个技术注意

- 字体要**嵌入**，否则换机变方块
- `✅❌⚠` 只有 Segoe UI Emoji 有字形，**换成文字**
- `−`（U+2212）在仿宋/宋体缺字形，**改用 ASCII `-`**
- `？？！` 等全角连用改为单个标点
