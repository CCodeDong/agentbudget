## 四、隐私政策托管（第 3 项）⭐ 这是最省事的一项

### 已生成的文件

```
privacy/
├── 隐私政策.md      ← 源文，便于修改
└── index.html       ← 可直接托管的页面（自适应深色模式，无依赖）
```

### 托管到 GitHub Pages（免费，10 分钟）

1. 在 GitHub 新建一个**公开**仓库，例如 `offlinelib-privacy`
2. 把 `index.html` 上传到仓库根目录（**文件名必须是 `index.html`**）
3. 仓库 **Settings → Pages**
4. Source 选 **Deploy from a branch**，Branch 选 `main`，目录选 **`/ (root)`**
5. 保存，等 1–2 分钟
6. 页面地址就是：
   ```
   https://<你的GitHub用户名>.github.io/offlinelib-privacy/
   ```

**把这个地址填进 AGC 的「隐私政策 URL」栏。**

> 为什么用 GitHub Pages：免费、稳定、不需要备案、不需要服务器。
> 隐私政策是静态页面，不需要任何后端。
