## 代码仓进度（仓颉语言程序设计）

仓颉侧交付物是一个**算法库**，没有图形界面，因此「进度」以可复跑的测试与实验数据呈现：

| 指标   | 值                                         | 口径                          |
| ------ | ------------------------------------------ | ----------------------------- |
| 源码   | **8 个文件**                               | `projects/agentbudget4cj/src` |
| 行数   | **1,678 行（含空行）／1,527 行（去空行）** | 两个数都真实，**不可混用**    |
| 测试   | **36 个 `@Test`**                          | 29 个功能测试 + 7 个基准      |
| 实验   | **11 个套件 / 3,960 次逐次运行**           | 原始数据在 `experiments/`     |
| 覆盖率 | 行 88.6% ／ 分支 66.8%                     | `cjcov` 产出                  |

复现方式：

```powershell
cd projects\agentbudget4cj
cjpm test        # 29 个功能测试
cjpm run         # 运行 CLI，打印每步调度决策与理由
```

> ⚠️ 仓颉工程路径**不能含中文**——含 `import` 时 `cjpm build` 会因编码不一致失败。
> 仓库中的 `tools/cj.ps1` 已通过 ASCII 镜像处理。
