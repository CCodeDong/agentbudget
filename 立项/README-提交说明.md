## 一·补　关于相机（若被问到，按这个答）

> **相机是有意放弃的，不是没做。**
> 调相机要 `ohos.permission.CAMERA`，而「零权限」是本应用的核心主张——
> 两者不可兼得，我们选了零权限。
> 用户拍照用系统相机，再经**系统相册选择器**导入，应用侧不承担该权限。
> 相册选择器与文件选择器都是系统组件，**都不需要申请权限**。


> **开题答辩 PPT 已在其他位置准备好**，不在本文件夹内（按你的说明，PPT 不在此处理）。

```powershell
cd projects\agentbudget4cj
```
